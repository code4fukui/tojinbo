# tojinbo

福井県の「東尋坊」の特徴的な岩場を共有・探検するためのウェブアプリケーションです。ユーザー投稿の写真、インタラクティブなVRマップ、AIチャットボット、ゲーミフィケーション要素を備えています。

- **ライブデモ:** [iwapp (開発中)](https://iwapp.code4fukui.org/)

## 機能

- **岩スポット**: ユーザーは面白い形をした岩の写真をアップロードし、ニックネームや何に見えるか（例：「ハート」「犬」）の説明を付けることができます。
- **「いいわん」システム**: 訪問者は「いいわん」（「良い岩」と犬の鳴き声のダジャレ）ボタンを使って、お気に入りの岩の写真に投票できます。
- **インタラクティブなVRマップ**: 東尋坊の崖の3Dモデルを探索できます。マップには、見どころへ移動するためのクリック可能な矢印が含まれています。
- **AIチャットボット「いわんわん」**: 東尋坊の案内犬「いわんわん」に質問してみましょう。東尋坊の歴史や観光スポットについて、語尾に「わん」を付けた役立つ回答を提供します。
- **岩コインのゲーミフィケーション**: 岩の写真投稿やゴミ拾いイベントへの参加などのアクティビティを通じて、仮想の「岩コイン」を獲得できます。コインは景品と交換可能です。
- **イベント＆アクティビティ**: ホームページにはイベント一覧やアクティビティへのリンクが掲載されており、「東尋坊VRジェットコースター」の動画も含まれています。

## はじめに

### 前提条件

- [Deno](https://deno.land/) ランタイム

### ローカル開発

ローカルマシンでサーバーを実行するには：

```bash
deno run -A server.js
```

アプリケーションは `http://localhost:8000` で利用可能になります。

## サーバー管理とデプロイ

以下の手順では、リモートサーバーへのアプリケーションのデプロイおよび管理方法について説明します。

### 1. SSH初期設定（初回のみ）

まだローカルマシンでSSH鍵ペアを生成していない場合は、生成してください。

```bash
# .sshディレクトリが存在しない場合は作成
mkdir -p ~/.ssh

# 新しいed25519鍵ペアを生成
ssh-keygen -t ed25519

# 公開鍵をコピーするために表示
cat ~/.ssh/id_ed25519.pub
```

サーバー側で、公開鍵を `authorized_keys` ファイルに追加します。

```bash
# 'iwapp'ユーザーとしてサーバーで実行
mkdir -p ~/.ssh
chmod 700 ~/.ssh
touch ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

# 前のステップから公開鍵を貼り付けて追加
echo "ssh-ed25519 AAAA..." >> ~/.ssh/authorized_keys
```

### 2. 接続と更新のデプロイ

SSH経由でサーバーに接続し、プロジェクトディレクトリに移動します。

```bash
ssh -i ~/.ssh/id_ed25519 iwapp@iwapp.code4fukui.org
cd tojinbo
```

GitHubリポジトリから最新の変更をプルします。

```bash
git pull
```

### 3. アプリケーションプロセスの管理

**実行中のプロセスを確認**

サーバーが既に実行中かどうかを確認するには、`ps` コマンドを使用します。

```bash
ps -fu iwapp
```
*出力例:*
```
UID          PID    PPID  C STIME TTY          TIME CMD
iwapp     668120       1  0 Jun17 ?        00:00:00 deno run -A server.js 8009
```

**プロセスを停止**

`ps` の出力で確認したプロセスID（PID）を指定して、`kill` コマンドを使用します。

```bash
# 上記の例のPIDを使用
kill 668120
```

**プロセスを開始**

サーバーをバックグラウンドで実行するには、`nohup` と `&` を使用します。

```bash
# 標準的な起動
nohup deno run -A server.js 8009 &

# ファイル変更時に自動再起動（開発用）
nohup deno run -A --watch server.js 8009 &
```

## APIエンドポイント

サーバーは、岩データを管理するためのシンプルなJSONベースのAPIを提供します。

- **`POST /api/save`**
  - 新しい岩の写真投稿を保存します。サーバーは自動的に一意の `id` を追加し、`likecount` を0に初期化します。
  - **リクエストボディ:**
    ```json
    {
      "img": "data:image/jpeg;base64,...",
      "nickname": "string",
      "comment": "string",
      "genderm": boolean,
      "genderf": boolean
    }
    ```

- **`GET /api/watch`**
  - 保存されているすべての岩データオブジェクトの配列を取得します。

- **`POST /api/like`**
  - 特定の岩投稿の `likecount` をインクリメント（増加）します。
  - **リクエストボディ:**
    ```json
    {
      "id": "unique-rock-id-string"
    }
    ```
  - **戻り値:** 新しい `likecount` の数値を返します。
